# Conecta-Timidez

Projeto escolar demonstrativo feito com HTML, CSS e JavaScript puro.

## Como executar
1. Baixe e extraia `conecta-timidez.zip`.
2. Abra a pasta `conecta-timidez`.
3. Dê dois cliques em `index.html` para abrir no navegador (Chrome, Edge ou Firefox).
4. Para testar, edite o perfil e os interesses, veja como os matches mudam, marque desafios, abra uma sugestão de conversa e publique no mural.

Não é necessário instalar programas, usar servidor ou configurar banco de dados.

## Funcionalidades
- Layout responsivo em azul e branco.
- Perfil personalizável com nome, apresentação e interesses.
- Sugestões de perfis fictícios ordenadas por interesses compartilhados.
- Filtro de interesses e cálculo demonstrativo de afinidade.
- Desafios progressivos com acompanhamento de conclusão.
- Fórum local com publicações de exemplo e botão de apoio.
- Janela com sugestão de mensagem que não envia mensagens reais.

## Limitações importantes
Esta é uma demonstração de front-end. As alterações ficam na memória da página e podem desaparecer ao atualizar. Não há contas reais, autenticação, banco de dados, chat em tempo real ou publicação na internet. Os perfis são fictícios. Para publicar para usuários reais, será necessário desenvolver um backend, armazenamento seguro, moderação, controle de acesso e ferramentas de denúncia/bloqueio.

O site usa uma fonte do Google Fonts quando há conexão com a internet; se estiver offline, uma fonte de sistema será usada.
